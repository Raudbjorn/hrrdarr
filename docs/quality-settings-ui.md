# Global quality settings

The Quality settings workspace edits the complete TV and movie quality catalogs separately. It displays immutable quality names and editable titles, minimum/preferred/maximum sizes, API-provided domain limits and optional read-only catalog defaults. Blank size fields mean null, distinct from zero. Numeric validation rejects non-finite/out-of-range values and inverted supplied bounds.

Saving sends one atomic native bulk request containing only changed rows, each with its title and all three size fields. This avoids propagating untouched TV definitions into profile overrides. A changed TV row with any nonnull size copies all three sizes into matching profile leaves, including nulls; an all-null row leaves profile overrides intact. The UI explains this consequence, including title-only edits. Movie edits do not propagate profile overrides.

Reset requires explicit confirmation with an optional title-reset checkbox. TV reset preserves all sizes; movie reset restores catalog size defaults. Both preserve titles unless selected. Cancelling does not write. Editing or starting a read cancels pending reset intent. Request failures preserve drafts; uncertain write outcomes block saves/resets until explicit reload of saved settings. Navigation preserves the draft. There is no automatic mutation retry or optimistic-concurrency guarantee.

After a successful or uncertain global write, the owning domain's open profile editor retains its draft, cancels deletion intent and blocks saves/deletion until explicit reopening. Catalog refresh alone does not clear this stale state. Reopening fetches current profile values and catalog labels. Movie changes do not invalidate TV drafts. A shared per-domain guard blocks either panel's writes while the other panel is writing or has an unresolved outcome. Reconciliation must happen in the panel that owns the uncertain write; reading a profile during an unresolved global write leaves that draft stale. The API still has no revision precondition, so changes from other clients cannot be prevented by this local coordination.
